# 🧪 Suíte de Testes Automatizados E2E - Automation Exercise

Projeto de automação de testes End-to-End (E2E) desenvolvido com **Cypress** para a plataforma [Automation Exercise](https://automationexercise.com/).

## 🚀 Tecnologias Utilizadas

- **Cypress**: Framework de testes automatizados
- **Node.js**: Ambiente de execução JavaScript
- **JavaScript (ES6+)**: Linguagem de programação
- **Git & GitHub**: Versionamento de código

## 📋 Cenários Automatizados

- `cadastro.cy.js`: Registo de novos utilizadores com dados dinâmicos (`Date.now()`).
- `login.cy.js`: Autenticação de utilizadores registados e fluxo de logout.
- `login-invalido.cy.js`: Validação de mensagens de erro para credenciais incorretas e utilizadores inexistentes.
- `carrinho.cy.js`: Fluxo completo de E-commerce (Registo, Seleção de Produto, Adição ao Carrinho, Checkout e Simulação de Pagamento com Cartão de Crédito).
